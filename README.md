# 🎨 Portal de Luhé

Un sitio web interactivo y personalizado creado con mucho cariño para Luhé, con el objetivo de alegrarle el día.

## ✨ Características

- **Rincón Interactivo:** Mensajes especiales, árbol de estados de ánimo y sonidos relajantes
- **Minijuegos:** Memory de gatitos y generador de doodles aleatorios
- **Zona de Doodles:** Pizarra digital para dibujar con diferentes colores y grosores
- **Diseño Personalizado:** Colores violeta y azul, temática moderna con toques doodle
- **Totalmente Responsive:** Se adapta a dispositivos móviles y desktop

## 🚀 Cómo Usar

1. **Acceder al sitio:** Simplemente abre el archivo `index.html` en cualquier navegador moderno
2. **Navegar:** Usa el menú superior para explorar las tres secciones
3. **Interactuar:**
   - Pasa el cursor sobre los iconos para ver mensajes
   - Juega al memory de gatitos
   - Dibuja en la pizarra digital
   - Genera doodles aleatorios

## 🛠️ Tecnologías Utilizadas

- HTML5, CSS3, JavaScript (ES6)
- [Howler.js](https://howlerjs.com/) - Para los sonidos
- [Font Awesome](https://fontawesome.com/) - Iconos
- [Google Fonts](https://fonts.google.com/) - Tipografías
